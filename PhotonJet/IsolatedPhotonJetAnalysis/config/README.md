# Configuration

V1 contains only the dataset manifests consumed by the histogram-receipt and
plot-contract path. The renderer rejects free-form sample prose: collision
system, sample kind, energy, centrality, event count, and status are formatted
only from validated `PhotonJetDatasetManifestV1` fields.

A resolved full-analysis configuration, p+p/Au+Au overlays, model references,
and run-manifest integration will be added only with strict loading, validation,
receipt binding, and mutation tests. No unconsumed nominal YAML is shipped as
if it controlled the current CLI.
