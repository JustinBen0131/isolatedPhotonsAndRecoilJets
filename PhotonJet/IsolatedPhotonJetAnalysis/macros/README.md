# Fun4All entry point

`Fun4All_RunPhotonJet.C` will be added only with the producer compatibility
facade and its p+p/Au+Au mini-DST differential. The downstream package does
not manufacture a nominal Fun4All macro that depends on private include paths.

`PhotonJetPlotStyle.h` draws the exact canonical
`#it{#bf{sPHENIX}} Internal` TLatex mark and a generated annotation block in a
verified data-free band inside the plotting frame. Individual plots never use
an external whitespace header. The helper intentionally accepts no free-form
physics labels.
