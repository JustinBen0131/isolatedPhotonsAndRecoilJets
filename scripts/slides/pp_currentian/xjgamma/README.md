# p+p photon-jet slide generators

These generators turn qualified p+p photon-jet artifacts into full-slide PNGs
and provenance sidecars. They distinguish reconstruction-level comparisons
from unfolded results and retain the selection, normalization, and claim
boundaries used by each candidate.

Reference documents are optional local inputs. Supply them through the
documented command-line option or environment variable; no personal path is
embedded in the public code.
