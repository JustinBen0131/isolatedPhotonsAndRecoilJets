# Photon-jet response and unfolding slide generators

This directory contains focused visualization consumers for response matrices,
closure checks, subtraction diagnostics, threshold scans, and p+p/Au+Au
photon-jet balance overlays. The generators read existing analysis products;
they do not run reconstruction or submit production.

Outputs are statistical or diagnostic candidates unless the emitted manifest
explicitly records all required correction, covariance, and closure gates.
