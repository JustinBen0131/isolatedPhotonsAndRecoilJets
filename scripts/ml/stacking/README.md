# Can stacking improve photon identification in heavy-ion collisions?

In a gold–gold collision, many particles deposit energy in the calorimeter near a photon candidate. A boosted decision tree and a multilayer perceptron can respond differently to the same shower. Justin Bennett led a series of comparisons to test whether a second classifier could use their scores to separate prompt photons from background more reliably. The study compared linear, neural and gradient-boosting meta-learners and examined how conclusions depended on the training split and the inputs available to the second stage.

The scripts here implement those experiments. The Au+Au analysis selected an XGBoost photon classifier for its nominal identification. Stacked classifiers remained alternatives. For the model used in the analysis, the separate PhotonID package documents training, calibration, working points and evaluation.

## How the experiments were set up

- The sweep can combine the BDT and MLP scores and, in selected variants, add kinematic, centrality or shower-shape information. Its GBM meta-learner is scikit-learn’s `GradientBoostingClassifier`. [Model sweep](train_auau_stacked_bdt_mlp_sweep.py)
- The staged workflow has separate out-of-fold and simple-holdout modes. In the five-fold configuration each base score used to build the stack is generated by a model that excluded that fold. One fold is held aside for stack validation. The simple-holdout mode uses a different partition. [Staged training and split definitions](train_photon_bdt_mlp_oof_stack_staged.py)
- The experimental comparisons used held-out performance and background rejection at a chosen signal efficiency. A comparison on simulated candidates and a data-driven purity check answer different questions. The training code documents which events and scores enter each experiment.
